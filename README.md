# WE IT — CIO Forward Predictions (public files)

This repository holds only the public files of https://kumarshakti.com/it/ :

- `it/index.html` — the page
- `it/predictions.json` — the same predictions in machine-readable form
- `it/BUILD.json` — build record (ledger hash, record count, build time, file hashes)

The files are generated automatically from WE IT's frozen forward-prediction ledger after each forecast freeze and each settlement of matured outcomes. Every displayed prediction is verified against the frozen ledger before it is published here.

**Experimental research. Not investment advice. Not a guarantee of returns.**
